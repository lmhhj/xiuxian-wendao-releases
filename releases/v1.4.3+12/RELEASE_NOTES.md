# 修仙问道 1.4.3+12

Android、iOS、macOS、Windows 统一版本 **1.4.3+12**。

## 本次更新

- 单人历练与双人秘境可同时进行，分别计时、消耗体力和领取奖励，具体资格与次数以游戏内规则为准。
- 分别展示两种历练的进行中和待领取状态，领取一种活动的奖励不影响另一种活动。
- 单人历练出发减少对双人秘境状态读取的等待，出发资格仍以游戏内校验为准。
- 返回近期页面时可先浏览已有内容，最新资料同步后再开放购买等交易操作，减少空白等待。
- 读取较慢时可主动重新连接；首次读取失败后不再反复空白转圈，重新连接后的旧结果不会覆盖当前页面。
- 优化首次进入时的角色与图鉴加载，减少等待。
- 保留前后台切换、药园滚动和播种后阅读位置等体验修复。

新玩法随仙界更新开放，具体资格、次数和奖励以游戏内显示为准。

## 下载与安装

| 设备 | 安装文件 | 要求与说明 |
| --- | --- | --- |
| Android | `xiuxian-wendao-1.4.3+12-android-arm64.apk` | Android 7.0+、ARM64；沿用原签名，可覆盖更新 |
| iPhone / iPad | `xiuxian-wendao-1.4.3+12-ios-unsigned.ipa` | iOS 15+；安装前需重新签名 |
| Mac | `xiuxian-wendao-1.4.3+12-macos-universal.dmg` | macOS 12+；Intel / Apple Silicon 通用，另提供同版本 ZIP |
| Windows | `xiuxian-wendao-1.4.3+12-windows-x64-portable.zip` | Windows 10 1809+ / Windows 11、x64；完整解压后运行 |

Mac 先退出旧版，再将新版拖入“应用程序”覆盖安装；当前未公证。Windows 完整解压便携包后运行 `xiuxian_wendao.exe`，保留全部 DLL 和 data 目录；当前未配置代码签名。

更新后使用原账号登录，云端角色和修行进度继续保留。`SHA256SUMS.txt` 可用于核对安装包完整性。
