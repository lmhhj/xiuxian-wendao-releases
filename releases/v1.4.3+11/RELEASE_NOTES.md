# 修仙问道 1.4.3+11

Android、iOS、macOS、Windows 统一版本 **1.4.3+11**。

## 本次更新

- 新增仙界拍卖，可参与珍稀物品竞价，查看出价、倒计时与成交结果。
- 新增全服动态公屏，查看道友突破、珍稀掉落、仙市交易及拍卖消息。
- 新增公开成交记录，查看近期仙市成交情况及本人售出记录。
- 双人秘境奖励升级，新增灵材和灵兽碎片，并有机会获得稀有丹药与装备，奖励预览更加清晰。
- 宗门悬赏材料按坊市标准价全额补偿，分别展示材料补偿、额外奖金和宗门贡献。
- 完善历练提示：单人历练与双人秘境进行中不能同时开启；结束后尚未领奖也可开始另一种历练。
- 首页补充装备、主修功法的战力加成，分别展示兵器基础战力与淬炼加成。
- 完善仙市商品属性、用途、所需境界，以及越级物品的使用、装备和上架提示。
- 减少宗门、仙市、药园等页面的加载等待，改善切页、滚动和返回前台的流畅度。
- 修复后台刷新时收取修为等按钮长时间不可点击的问题，结算反馈更及时，刷新时保持阅读位置。

新玩法随仙界开放，具体资格、奖励和拍卖安排以游戏内显示为准。

## 下载与安装

| 设备 | 安装文件 | 要求与说明 |
| --- | --- | --- |
| Android | `xiuxian-wendao-1.4.3+11-android-arm64.apk` | Android 7.0+、ARM64；沿用原签名，可覆盖更新 |
| iPhone / iPad | `xiuxian-wendao-1.4.3+11-ios-unsigned.ipa` | iOS 15+；安装前需重新签名 |
| Mac | `xiuxian-wendao-1.4.3+11-macos-universal.dmg` | macOS 12+；Intel / Apple Silicon 通用，另提供 ZIP |
| Windows | `xiuxian-wendao-1.4.3+11-windows-x64-portable.zip` | Windows 10 1809+ / Windows 11、x64；完整解压后运行 |

Mac 先退出旧版，再将新版拖入“应用程序”覆盖安装；当前未公证。Windows 完整解压便携包后运行 `xiuxian_wendao.exe`，保留全部 DLL 和 data 目录；当前未配置代码签名。

更新后使用原账号登录，云端角色和修行进度继续保留。`SHA256SUMS.txt` 可用于核对安装包完整性。
