# 修仙问道 1.4.7+16

Android、iOS、macOS 和 Windows 使用相同的版本号。下列玩法在启用重开服规则的仙界生效。

## 本次更新

- **邀请码和道号**重开服使用一次性邀请码注册。账号与道号分别校验重名，每个账号可创建一名角色。
- **五灵根入世**重开服的新角色统一从五灵根开始。后续可通过灵根洗炼改变资质。
- **历练和养成**所有单人地图共用每天十次额度，每次十五分钟。重开服静修从筑基起每跨一个大境界按 2 倍成长，小境界战力提升增加。
- **成就观览**进入「道我」查看 90 枚原创勋章及解锁进度，已修正勋章边缘的残留图案。每枚勋章可领 100 灵石，可在洞府展示一枚勋章的称号和解锁总数。
- **每日悬赏**新增药园采收、双人秘境、论道获胜、宗门任务和双修。论道日结第一名为 1,000 灵石，开创宗门需 50,000 灵石。
- **丹房和灵根**同种丹药成功炼成十份永久增加一个百分点的成功率。雷灵根的突破加成调整为十二个百分点。
- **突破和渡劫**结丹初期保留原成功率，从结丹中期开始逐步增加难度。大境界越高，破境基础成功率越低。

新增药园被摘、普通论道落败、宗门材料悬赏、灵根洗炼、炼丹失败和同次掉落装备与丹药六类成就，共 18 枚。新进度从服务端更新起计算。全部称号和条件见[成就勋章图鉴](ACHIEVEMENTS.md)。

## 下载安装

| 设备 | 文件 | 要求与说明 |
| --- | --- | --- |
| Android | `xiuxian-wendao-1.4.7+16-android-arm64.apk` | Android 7.0+，ARM64，沿用原签名 |
| iPhone / iPad | `xiuxian-wendao-1.4.7+16-ios-unsigned.ipa` | iOS 15+，安装前需签名 |
| Mac | `xiuxian-wendao-1.4.7+16-macos-universal.dmg` | macOS 12+，支持 Intel 和 Apple Silicon，另有备用 ZIP |
