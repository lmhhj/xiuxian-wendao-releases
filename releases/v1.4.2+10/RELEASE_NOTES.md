# 修仙问道 1.4.2+10

Android、iOS、macOS、Windows 统一版本 **1.4.2+10**。

## 本次更新

- 新增炼器阁，查看兵器淬炼阶数、真实材料需求和额外战力，换装保留角色淬炼进度。
- 宗门宝库新增商品简介与效果详情，按实际报价展示贡献和优惠。
- 新增双人协作秘境，邀请道友组队、查看进度并独立领取本人的奖励。
- 宗门新增材料悬赏，分别显示材料补偿、额外奖金、实际灵石总额和宗门贡献。
- 首页和道友资料补充兵器淬炼信息，新增六种炼器材料专属图标。
- 四端同步既有洞府装扮、人物加成、突破演出、背景音乐、药园与炼丹修复。

新玩法随仙界服务更新开放，是否开放及角色资格以游戏内显示为准。

## 下载与安装

| 设备 | 安装文件 | 要求与说明 |
| --- | --- | --- |
| Android | `xiuxian-wendao-1.4.2+10-android-arm64.apk` | Android 7.0+、ARM64；沿用原签名，可覆盖更新 |
| iPhone / iPad | `xiuxian-wendao-1.4.2+10-ios-unsigned.ipa` | iOS 15+；未签名，安装前需重签 |
| Mac | `xiuxian-wendao-1.4.2+10-macos-universal.dmg` | macOS 12+；Intel / Apple Silicon 通用，另提供 ZIP |
| Windows | `xiuxian-wendao-1.4.2+10-windows-x64-setup.exe` | Windows 10 1809+ / Windows 11、x64，另提供便携 ZIP |

Mac 先退出旧版，再将新版拖入“应用程序”覆盖安装；当前为临时签名，未公证。Windows 安装版直接运行安装器；便携版完整解压后运行 `xiuxian_wendao.exe`，保留全部 DLL 和 data 目录，程序与安装器未配置代码签名。

更新后使用原账号登录，云端角色和修行进度继续保留。`SHA256SUMS.txt` 可用于核对下载文件完整性。
