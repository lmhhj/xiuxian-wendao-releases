# 修仙问道 1.4.6+15

Android、iOS、macOS 和 Windows 统一为 **1.4.6+15**。新玩法和炼丹回收限价需要连接已更新的仙界服务端。

## 本次更新

- **道祖问道**新增五道参悟、战报复盘和专属成就。诸天试炼四境各 20 关，装备、功法与主骑搭配会影响战斗结果。
- **掌中世界**可建造、收徒、展示奇观并开放拜访。界源可从试炼、药园和历练获取，每天最多 24 点。
- **天道大劫**在太乙开启。全服修复阵眼、破除魔甲、迎战域外天魔，可以按战力出战或提交物资。
- **炼器阁和灵兽录**新增兵器锻造、法衣与护符强化。满级灵兽可强化至五阶，解锁变异形态、觉醒天赋和进化演出。
- **历练和炼丹**调整高阶丹药药效、配方和灵根加成，修复购买材料后靠炼丹回收赚差价的问题。单人历练缩短并可确认取消，双人秘境每天可参加五场。
- **药园、宗门和交易**支持购买土地、施肥和安装防盗网，调高宗门俸禄，支持按数量购买挂单。新增试道论剑、论剑周榜、道友搜索和口令兑换。

## 下载安装

| 设备 | 文件 | 要求与说明 |
| --- | --- | --- |
| Android | `xiuxian-wendao-1.4.6+15-android-arm64.apk` | Android 7.0+，ARM64，沿用原签名 |
| iPhone / iPad | `xiuxian-wendao-1.4.6+15-ios-unsigned.ipa` | iOS 15+，安装前需签名 |
| Mac | `xiuxian-wendao-1.4.6+15-macos-universal.dmg` | macOS 12+，支持 Intel 和 Apple Silicon，另有备用 ZIP |
| Windows | `xiuxian-wendao-1.4.6+15-windows-x64-setup.exe` | Windows 10 1809+ 或 Windows 11，另有便携 ZIP |

Mac 将应用拖入“应用程序”，应用使用临时签名。Windows 安装器未签名，使用便携包时请完整解压，再运行 `xiuxian_wendao.exe`。更新前请退出旧版，安装后用原账号登录。`SHA256SUMS.txt` 可用于核对下载完整性。
