# 修仙问道

一款以修仙养成为主题的手游。开辟洞府、吐纳突破、结契灵兽，与道友一同问道长生。

## 下载安装

打开本仓库的 **Releases**，选择最新版本，下载适合自己设备的安装包。

| 设备 | 下载文件 | 系统要求 |
| --- | --- | --- |
| Android | `.apk` | Android 7.0 及以上，64 位 ARM 设备 |
| iPhone / iPad | `.ipa` | iOS 15 及以上，安装前需重新签名 |

Android 下载 APK 后打开安装即可。iOS 当前提供未签名 IPA，请使用自己的签名方式签名后安装。

## 开启仙途

在 App 内注册或登录修仙账号，创建角色后先选择初始灵根，再进入世界修行。角色与修行进度保存在云端，换设备后登录同一账号即可继续。

每个账号只能创建一个角色。初始灵根可额外刷新20次，也可提前确认；第20次刷新后自动入世。最终以五灵根入世的新角色可自动获得1000灵石补助，具体资格以游戏内提示为准。

- **修行养成**：洞府吐纳、境界突破、渡劫历练、炼丹与功法修炼。
- **仙界游历**：灵兽结契、药园种植、坊市交易、宗门与道友互动。
- **炼丹心得**：同种丹药累计每失败5份，永久增加1个百分点，查看进度与当前成丹率。
- **药园保护**：新植株所有道友累计最多取走一成，按实际余量偷取与采收。
- **个性装扮**：在“道我 → 洞府装扮”统一设置洞府、本命法相、突破与渡劫图片，支持浅色、深色与跟随系统主题。
- **人物法相**：首页查看装备修炼加成、主修功法及主骑灵兽的等级与加成，以及宗门身份。
- **突破演出**：聚气蓄势后揭晓结果，配有金光飞升、雷劫和专属音效。
- **静修琴音**：竹笛古筝背景音乐，支持音量调整与试听，音乐和突破音效可分别关闭。
- **私下论剑**：同境道友双方确认，胜加20、负减20论道积分，不发放灵石，随仙界开放。

切回前台时保留正在浏览的页面与阅读位置，在后台同步最新仙途。

## 版本更新

更新内容请查看对应 Release 的版本说明。同一 Release 内 Android 与 iOS 使用相同的版本号。Android 覆盖更新需要使用相同签名的安装包；iOS 更新时仍需完成签名。

版本过旧时，App 会提示更新并提供下载入口。更新会保留原账号和云端角色，使用原账号登录即可继续修行。
