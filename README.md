# 修仙问道

一款以修仙养成为主题的游戏。开辟洞府、吐纳突破、结契灵兽，与道友一同问道长生。

## 下载安装

前往 **[Releases 下载最新版本](https://github.com/lmhhj/xiuxian-wendao-releases/releases)**，版本 **1.4.7+16**，四端版本一致。

| 设备 | 下载文件 | 系统要求 |
| --- | --- | --- |
| Android | `.apk` | Android 7.0 及以上，ARM64 |
| iPhone / iPad | `.ipa` | iOS 15 及以上，安装前需重新签名 |
| Mac | `.dmg`，另提供 `.zip` | macOS 12 及以上，Intel / Apple Silicon 通用 |
| Windows | 安装 `.exe` 或便携 `.zip` | Windows 10 1809 及以上 / Windows 11，x64 |

Android 打开 APK 安装。Mac 将应用拖入“应用程序”；当前未公证。Windows 打开 EXE 安装，使用便携包时完整解压后运行 `xiuxian_wendao.exe`。

## 开启仙途

在游戏内注册或登录修仙账号，创建角色后以五灵根入世修行。账号、角色和修行进度保存在云端，换设备后登录同一账号即可继续。

洞府吐纳、境界突破、渡劫历练、药园炼丹、功法与灵兽养成，搭配宗门、坊市和道友互动。支持自定义洞府与法相、突破演出和音效、背景音乐，以及浅色、深色和跟随系统主题。

## 1.4.7+16 更新

- 邀请码和道号重开服使用一次性邀请码注册。账号与道号分别校验重名，每个账号可创建一名角色。
- 五灵根入世重开服的新角色统一从五灵根开始。后续可通过灵根洗炼改变资质。
- 历练和养成所有单人地图共用每天十次额度，每次十五分钟。重开服静修从筑基起每跨一个大境界按 2 倍成长，小境界战力提升增加。
- 成就观览进入「道我」查看 90 枚原创勋章及解锁进度。每枚勋章可领 100 灵石，可在洞府展示一枚勋章的称号和解锁总数。

新增六类成就，修正勋章图片边缘。结丹中期起逐步提高突破与渡劫难度。详见[版本说明](releases/v1.4.7+16/RELEASE_NOTES.md)和[成就勋章图鉴](releases/v1.4.7+16/ACHIEVEMENTS.md)。

更新前先退出旧版。重开服开放后，请使用邀请码注册新账号并创建角色。Android 覆盖更新需使用相同签名，iOS 更新仍需签名。版本过旧时，游戏会提供更新提示和下载入口。
