# 修仙问道

一款以修仙养成为主题的游戏。开辟洞府、吐纳突破、结契灵兽，与道友一同问道长生。

## 下载安装

前往 **[Releases 下载最新版本](https://github.com/lmhhj/xiuxian-wendao-releases/releases)**，当前版本为 **1.4.3+12**，四端版本一致。

| 设备 | 下载文件 | 系统要求 |
| --- | --- | --- |
| Android | `.apk` | Android 7.0 及以上，ARM64 |
| iPhone / iPad | `.ipa` | iOS 15 及以上，安装前需重新签名 |
| Mac | `.dmg`，另提供 `.zip` | macOS 12 及以上，Intel / Apple Silicon 通用 |
| Windows | 便携 `.zip` | Windows 10 1809 及以上 / Windows 11，x64 |

Android 打开 APK 安装。Mac 将应用拖入“应用程序”；当前未公证。Windows 完整解压便携包后运行 `xiuxian_wendao.exe`；当前未配置代码签名。

## 开启仙途

在游戏内注册或登录修仙账号，创建角色并选择初始灵根后入世修行。账号、角色和修行进度保存在云端，换设备后登录同一账号即可继续。

洞府吐纳、境界突破、渡劫历练、药园炼丹、功法与灵兽养成，搭配宗门、坊市和道友互动。支持自定义洞府与法相、突破演出和音效、背景音乐，以及浅色、深色和跟随系统主题。

## 1.4.3+12 更新

- **历练并行**：单人历练与双人秘境可同时进行，分别计时和领取奖励。
- **活动状态更清楚**：分别展示两种历练的进行中与待领取状态。
- **出发更及时**：减少单人出发时的额外等待。
- **减少空白等待**：返回近期页面时先浏览已有内容，同步后再开放交易。
- **改善慢连接反馈**：读取较慢时可主动重新连接，失败后不再反复空白转圈。
- **优化首次进入**：减少角色与图鉴加载等待，保留药园和前后台切换的体验修复。

完整内容见[版本说明](releases/v1.4.3+12/RELEASE_NOTES.md)。

更新前先退出旧版，安装后使用原账号登录。Android 覆盖更新需使用相同签名，iOS 更新仍需签名。版本过旧时，游戏会提供更新提示和下载入口。
