# 修仙问道

一款以修仙养成为主题的游戏。开辟洞府、吐纳突破、结契灵兽，与道友一同问道长生。

## 下载安装

前往 **[Releases 下载最新版本](https://github.com/lmhhj/xiuxian-wendao-releases/releases)**，当前版本为 **1.4.2+10**，四端版本一致。

| 设备 | 下载文件 | 系统要求 |
| --- | --- | --- |
| Android | `.apk` | Android 7.0 及以上，ARM64 |
| iPhone / iPad | `.ipa` | iOS 15 及以上，安装前需重新签名 |
| Mac | `.dmg`，另提供 `.zip` | macOS 12 及以上，Intel / Apple Silicon 通用 |
| Windows | `setup.exe`，另提供便携 `.zip` | Windows 10 1809 及以上 / Windows 11，x64 |

Android 打开 APK 安装。Mac 将应用拖入“应用程序”；当前未公证。Windows 可运行安装器，或完整解压便携包后运行 `xiuxian_wendao.exe`；当前未配置代码签名。

## 开启仙途

在游戏内注册或登录修仙账号，创建角色并选择初始灵根后入世修行。账号、角色和修行进度保存在云端，换设备后登录同一账号即可继续。

洞府吐纳、境界突破、渡劫历练、药园炼丹、功法与灵兽养成，搭配宗门、坊市和道友互动。支持自定义洞府与法相、突破演出和音效、背景音乐，以及浅色、深色和跟随系统主题。

## 1.4.2+10 更新

- **炼器阁**：兵器淬炼、材料需求与额外战力展示。
- **宗门宝库**：商品简介、效果详情和实际优惠。
- **双人秘境**：邀请道友共同历练，各自领取奖励。
- **材料悬赏**：交付宗门材料，查看补偿、奖金和贡献明细。

新玩法随仙界服务更新开放，具体资格以游戏内显示为准。完整内容见[版本说明](releases/v1.4.2+10/RELEASE_NOTES.md)。

更新前先退出旧版，安装后使用原账号登录。Android 覆盖更新需使用相同签名，iOS 更新仍需签名。版本过旧时，游戏会提供更新提示和下载入口。
