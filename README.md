# 修仙问道

一款以修仙养成为主题的手游。开辟洞府、吐纳突破、结契灵兽，与道友一同问道长生。

## 下载安装

打开本仓库的 **Releases**，选择最新版本，下载适合自己设备的安装包。

| 设备 | 下载文件 | 系统要求 |
| --- | --- | --- |
| Android | `.apk` | Android 7.0 及以上，64 位 ARM 设备 |
| iPhone / iPad | `.ipa` | iOS 15 及以上，安装前需重新签名 |

Android 下载 APK 后打开安装即可。iOS 当前提供未签名 IPA，请使用自己的签名方式签名后安装。

## 开启仙途

在 App 内注册或登录修仙账号，创建角色后即可开始修行。角色与修行进度保存在云端，换设备后登录同一账号即可继续。

- **修行养成**：洞府吐纳、境界突破、渡劫历练、炼丹与功法修炼。
- **仙界游历**：灵兽结契、药园种植、坊市交易、宗门与道友互动。
- **个性装扮**：自定义洞府背景，支持浅色、深色与跟随系统主题。

## 版本更新

更新内容请查看对应 Release 的版本说明。Android 覆盖更新需要使用相同签名的安装包；iOS 更新时仍需完成签名。
